# Railway Resource Detector

<!--[goref-image]: https://pkg.go.dev/badge/go.opentelemetry.io/contrib/detectors/railway.svg-->

This module detects [resource](https://opentelemetry.io/docs/specs/otel/resource/sdk/)
attributes available when a Go application is running on [Railway](https://railway.com).

See the [package documentation](https://pkg.go.dev/go.opentelemetry.io/contrib/detectors/railway)
for the full list of detected attributes.
