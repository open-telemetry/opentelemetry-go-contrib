# Host instrumentation example

[![Go Reference](https://pkg.go.dev/badge/go.opentelemetry.io/contrib/instrumentation/host/example.svg)](https://pkg.go.dev/go.opentelemetry.io/contrib/instrumentation/host/example)

Collects host metrics and writes them to standard output once per second.

From the repository root:

```sh
cd instrumentation/host/example
go run .
```

Stop the program with Ctrl+C.
