# otelsarama

[![Go Reference](https://pkg.go.dev/badge/go.opentelemetry.io/contrib/instrumentation/github.com/IBM/sarama/otelsarama.svg)](https://pkg.go.dev/go.opentelemetry.io/contrib/instrumentation/github.com/IBM/sarama/otelsarama)

Package `otelsarama` provides OpenTelemetry instrumentation for the
[github.com/IBM/sarama](https://github.com/IBM/sarama) Kafka client library.

## Compatibility

This package requires sarama v1.43.3 or later and Go 1.25 or later.
